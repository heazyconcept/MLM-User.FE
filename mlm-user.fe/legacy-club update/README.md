# Segulah Global Legacy Club

Add-on membership programme on top of an activated Segulah Global account. It is **not** a new registration package and **not** part of the matrix.

| Phase | What ships | Docs |
|---|---|---|
| **1 — Join, Instant, menu** | Menu, packages, Legacy marketplace + **Legacy voucher**, Instant + Successline bonus into **Legacy account**, cashout with **no referrals**, auto-sponsor if Segulah upline is already in Legacy Club | [Context](./phase-1-context.md) · [UI/UX](./phase-1-ui-ux.md) · [Backend](./phase-1-backend.md) · [Frontend integration](./phase-1-frontend-integration.md) |
| **2 — Monthly & Autoship** | 30-day monthly (base until 3 Successlines, then **increased** from the next month), pending until Autoship on **Legacy voucher**, drop into Legacy account, no cashout lock | [Context](./phase-2-context.md) · [UI/UX](./phase-2-ui-ux.md) · [Backend](./phase-2-backend.md) · [Frontend integration](./phase-2-frontend-integration.md) |
| **3 — Upgrade & reactivation** | Upgrade by difference (Legacy voucher), Instant to **Legacy account**, clock restarts, reactivate after 6 months **keeps increased monthly**, history | [Context](./phase-3-context.md) · [UI/UX](./phase-3-ui-ux.md) · [Backend](./phase-3-backend.md) · [Frontend integration](./phase-3-frontend-integration.md) |
