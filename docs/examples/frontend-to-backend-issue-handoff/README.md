# Frontend → Backend issue handoff (example pack)

Copy this folder into another project when you want frontend teams (and their agents) to file backend bugs and API requests in one consistent format.

| File | Role |
|------|------|
| [MEETING_TALKING_POINTS.md](./MEETING_TALKING_POINTS.md) | Your script for explaining this in a meeting |
| [BACKEND_ISSUE_GUIDE.md](./BACKEND_ISSUE_GUIDE.md) | Rules + checklist (hand to the other team) |
| [BACKEND_BUG_TEMPLATE.md](./BACKEND_BUG_TEMPLATE.md) | Empty bug template |
| [BACKEND_REQUEST_TEMPLATE.md](./BACKEND_REQUEST_TEMPLATE.md) | Empty request template |
| [examples/EXAMPLE_BACKEND_BUG.md](./examples/EXAMPLE_BACKEND_BUG.md) | Filled bug sample |
| [examples/EXAMPLE_BACKEND_REQUEST.md](./examples/EXAMPLE_BACKEND_REQUEST.md) | Filled request sample |

For the meeting: use talking points + the two examples. Hand them the guide + templates afterward.
